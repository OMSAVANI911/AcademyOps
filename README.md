# AcademyOps — Lead-to-Enrollment Management System

## Project Purpose
AcademyOps is a lead-to-enrollment management system built for EasySkill Career Academy (ECA). It captures leads from marketing channels, tracks them through a defined sales pipeline, and provides analytics on funnel performance.
